# StoreOS Designsystem

Kleines Flutter-Package für die P0-Oberfläche: Material-3-Theme, Abstände und ein zugängliches Statuspanel. Fachliche Zustände und API-Daten bleiben im Client beziehungsweise im Server; das Designsystem stellt nur Darstellung bereit.

```powershell
cd packages/design_system
flutter test
```
